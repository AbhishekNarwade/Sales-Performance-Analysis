# # Sales Performance Analysis Dashboard

## Project Overview
Developed an interactive sales performance analysis project using Microsoft Excel to analyze revenue trends and business performance.

## Key Features
- Interactive dashboard with PivotTables and PivotCharts
- Sales analysis by product, city, region, and category
- Revenue analysis over time
- Interactive slicers for filtering and exploring sales data
- Business insights to support data-driven decisions

## Tools & Technologies
- Microsoft Excel
- PivotTables and PivotCharts
- Excel Slicers
- Data Analysis and Visualization

## Project File
Download the Excel project file from this repository and open it in Microsoft Excel to explore the analysis and dashboard.
